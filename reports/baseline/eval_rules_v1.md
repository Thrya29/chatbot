Generated by `python evals/run_evals.py`. All conversations are synthetic and hand-labelled.
The **dev** set is what the rules were tuned on. The **held-out** set was written once and never tuned on, so it is the honest number. Small samples: read the confidence intervals.

- Gate `selfharm_to_vulnerable_recall`: 1/1 = 100% (95% CI 21–100%); zero misses in 1 still allows up to ~300% (rule of three)
