# Detection and routing evaluation (rules only)

Generated by `python evals/run_evals.py`. All conversations are synthetic and hand-labelled.
- **dev**: what the rules were tuned on. Expect it to look good.
- **held-out v1**: written blind for rules v1, which reached a person in only 37% of the cases that needed one (frozen in `reports/baseline/eval_rules_v1.md`). Rules v2 were then rewritten by concept after reading those misses, so this set is no longer blind and its v2 score is optimistic.
- **held-out v2 (blind)**: written after rules v2 were frozen and before running them on it. **This is the honest number.**

Samples are small, so read the confidence intervals, not the point estimates.
